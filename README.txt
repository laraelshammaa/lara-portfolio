HOW TO PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named: lara-portfolio
2. Open the repository and choose Add file > Upload files.
3. Upload index.html, style.css, and the assets folder (including the CV file). Do not upload only the ZIP file.
4. Commit the uploaded files to the main branch.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select Branch: main and Folder: /(root), then Save.
8. Wait a few minutes. The published URL should look like https://YOUR-USERNAME.github.io/lara-portfolio/.

Before publishing, check that the public phone number is one you are comfortable sharing. Project repository links can be added later when you have the GitHub repositories.
